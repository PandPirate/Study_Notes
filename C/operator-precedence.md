# C 运算符优先级

## 一、完整优先级表（从高到低）

| 优先级 | 运算符 | 描述 | 结合性 |
|:---:|--------|------|:---:|
| 1 | `()` `[]` `->` `.` | 括号 / 下标 / 结构体成员访问 | 左到右 |
| 2 | `!` `~` `++` `--` `+` `-` `*` `&` `(type)` `sizeof` | 一元运算符 | 右到左 |
| 3 | `*` `/` `%` | 乘 / 除 / 取模 | 左到右 |
| 4 | `+` `-` | 加 / 减 | 左到右 |
| 5 | `<<` `>>` | 左移 / 右移 | 左到右 |
| 6 | `<` `<=` `>` `>=` | 关系比较 | 左到右 |
| 7 | `==` `!=` | 相等 / 不等 | 左到右 |
| 8 | `&` | 按位与 | 左到右 |
| 9 | `^` | 按位异或 | 左到右 |
| 10 | `\|` | 按位或 | 左到右 |
| 11 | `&&` | 逻辑与 | 左到右 |
| 12 | `\|\|` | 逻辑或 | 左到右 |
| 13 | `?:` | 条件运算符（三目） | 右到左 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | 赋值 | 右到左 |
| 15 | `,` | 逗号 | 左到右 |

> 数字越小优先级越高，1 最高，15 最低。

## 二、重点：后缀运算符 vs 一元取地址

最容易混淆的是第一、二级：

- `->` 和 `.` 属于**第 1 级（后缀运算符）**，优先级最高。
- `&`（取地址）和 `*`（解引用）属于**第 2 级（一元前缀）**，次之。

因此：

```c
&p->next      等价于   &(p->next)     // 先取成员 next，再取 next 的地址
*p->next      等价于   *(p->next)     // 先取成员 next，再解引用
```

结合链表的例子：

```c
Node **pp = &cur->next;   // 等价于 &(cur->next)
```

这里取的是 `cur` 节点**成员 `next` 的地址**（类型是 `Node **`），而不是对 `cur` 取地址。

## 三、两个 `&` 别混淆

`&` 在不同位置含义不同、优先级也不同：

| 写法 | 含义 | 运算符类型 | 优先级 |
|------|------|-----------|:---:|
| `&a` | 取地址 | 一元前缀 | 2（高） |
| `a & b` | 按位与 | 二元 | 8（低） |

```c
p->flags & MASK     等价于   (p->flags) & MASK   // -> 优先级高于按位 &
a && b              逻辑与（优先级 11），低于按位 &
```

## 四、结合性

- **左结合**（多数运算符）：从左往右算。如 `a - b - c` 等价于 `(a - b) - c`。
- **右结合**（一元、条件、赋值）：从右往左算。如 `a = b = c` 等价于 `a = (b = c)`，`*p++` 等价于 `*(p++)`。

```c
int a, b, c;
a = b = c = 0;   // 右结合：等价于 a = (b = (c = 0))

*p++             // 右结合：先 p++（返回旧值），再对旧值解引用
(*p)++           // 先解引用，再对结果自增，语义不同
```

## 五、常见易错点

1. **`*p++` 与 `(*p)++`**：`*p++` 是先 `p++` 再 `*`（因为后缀 `++` 优先级高于 `*`）；`(*p)++` 是先解引用再自增。
2. **`&` 与 `==`**：`a & b == c` 等价于 `a & (b == c)`，因为 `==`（7 级）高于 `&`（8 级），容易写错，建议加括号 `(a & b) == c`。
3. **`<<` 与 `+`**：`a << b + c` 等价于 `a << (b + c)`，因为 `+`（4 级）高于 `<<`（5 级）。
4. **赋值与比较**：`if (a = b)` 是赋值不是比较，`=`（14 级）远低于 `==`（7 级），写错时编译器通常只给警告。

## 六、一句话总结

**后缀（`->` `.` `[]` `()`）> 一元（`&` `*` `!` `~`）> 算术 > 移位 > 关系 > 位运算 > 逻辑 > 条件 > 赋值 > 逗号**。拿不准时，加括号最稳妥。
